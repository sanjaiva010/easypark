How it works

  • 1. Pick a free (green) spot and reserve a time.
  • 2. Get a reservation reference code on screen.
  • 3. On arrival, scan the QR label on the spot — it opens this website showing that spot's live info.
  • 4. The LED on the spot turns green/yellow/red to match the on-screen status.
